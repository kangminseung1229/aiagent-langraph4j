# Hello Swagger App

Next.js App Router demo for Cursor Apps hosting.

## Run

```bash
cd hello-swagger-app
npm install
npm run dev
```

## Endpoints

| Path | Description |
|------|-------------|
| `/` | OpenAPI-style UI with Try it out |
| `GET /api/hello` | `{"message":"hello world"}` |
| `GET /api/openapi` | OpenAPI JSON |
